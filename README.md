# AquaPure website (static demo)

8 pages: Home, Products, Technology, Benefits, About, Gallery, Contact, FAQ.
Plain HTML + CSS + JavaScript. No install or build step needed.

## Run
Open `index.html` in a browser. Keep the `assets/` folder next to it.
Or serve the folder: `npx serve .` or `python3 -m http.server 8000` then open http://localhost:8000

## Notes
- Images in `assets/` are cropped from the supplied design mockup, so they are low resolution. Replace them with original product photography (same file names keep everything working).
- Phone, email, address, specifications and the 99.9% style claims are sample values from the mockup. Confirm before launch.
- The contact form is a demo. It validates input and shows a local confirmation, but sends nothing.
- Not built with React/Vite/Tailwind/Framer Motion because package installs were unavailable.
